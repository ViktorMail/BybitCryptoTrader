# 🚀 Bybit Crypto Trader v2.0

Автоматический мониторинг и покупка криптовалют на бирже Bybit с графическим интерфейсом для Windows.

## ✨ Новые возможности v2.0

- **🖥️ GUI интерфейс** - удобный графический интерфейс для Windows
- **🔧 Мастер настройки** - пошаговая настройка через диалоговые окна
- **🎯 Выбор криптовалют** - выбор из полного списка Bybit с реальными ценами
- **📊 Живые графики** - визуализация изменений цен
- **💰 Ручная торговля** - возможность покупки через интерфейс
- **⚙️ Гибкие настройки** - настройка всех параметров через GUI

## 🚀 Основные возможности

- **Мониторинг цен** - отслеживание цен выбранных криптовалют в реальном времени
- **Автоматическая покупка** - покупка при падении цены на заданный процент
- **Настраиваемые пороги** - индивидуальные пороги покупки для каждой криптовалюты
- **Лимиты сделок** - ограничение количества сделок в день
- **Безопасность** - поддержка testnet для тестирования
- **Два режима работы** - графический интерфейс и консольный режим

## ⚙️ Настройка

### 1. Получение API ключей Bybit

1. Зарегистрируйтесь на [bybit.com](https://www.bybit.com)
2. Перейдите в раздел **API Management**
3. Создайте новый API ключ с правами на торговлю spot
4. Скопируйте API Key и API Secret в файл `.env`

### 2. Настройка торговых параметров

Отредактируйте файл `config.py`:

```python
USER_SETTINGS = {
    # Список криптовалют для мониторинга
    'watchlist': [
        'BTCUSDT',
        'ETHUSDT', 
        'ADAUSDT',
        'SOLUSDT',
        'DOTUSDT'
    ],
    
    # Настройки покупки
    'auto_buy_enabled': False,  # Измените на True для включения автопокупки
    'buy_amount_usdt': 10.0,    # Сумма покупки в USDT
    'max_daily_trades': 5,      # Максимум сделок в день
    
    # Пороговые значения для покупки (процентное падение цены)
    'buy_thresholds': {
        'BTCUSDT': -5.0,   # Покупать при падении на 5%
        'ETHUSDT': -4.0,   # Покупать при падении на 4%
        'ADAUSDT': -6.0,   # Покупать при падении на 6%
        'SOLUSDT': -5.5,   # Покупать при падении на 5.5%
        'DOTUSDT': -5.0    # Покупать при падении на 5%
    },
    
    # Целевые криптовалюты для покупки (выберите нужные)
    'target_symbols': ['BTCUSDT'],  # Только эти будут покупаться
}
```

## 🎯 Выбор криптовалют для покупки

Чтобы выбрать криптовалюты для автоматической покупки, измените список `target_symbols` в `config.py`:

```python
# Пример: покупать только Bitcoin и Ethereum
'target_symbols': ['BTCUSDT', 'ETHUSDT']

# Пример: покупать все из watchlist
'target_symbols': ['BTCUSDT', 'ETHUSDT', 'ADAUSDT', 'SOLUSDT', 'DOTUSDT']
```
